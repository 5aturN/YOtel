# Журнал изменений

## [0.1.0] — 2026-10-09

Первый учебный прототип «ЯОтель».

### Добавлено
- Health-check `GET /health`.
- Каталог демонстрационных номеров и поиск доступности по датам и числу гостей.
- Создание бронирования со статусом `pending` и запрет пересечения активных интервалов.
- Расчёт суммы в копейках с повышенным тарифом для ночей, начинающихся в пятницу и субботу.
- GitHub Actions для сборки контейнера, unit-тестов и статического анализа.

### Ограничения версии
- API защищён межсервисным ключом; пользовательская аутентификация и разграничение по владельцу будут добавлены до стабильного релиза.
- Платежи, электронные замки и внешняя доставка email не входят в этот прототип.
