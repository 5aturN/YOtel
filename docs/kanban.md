## Ограничение доски

В этой сессии GitHub CLI не имеет OAuth scope `read:project`, поэтому настоящий GitHub Projects board создать/прочитать нельзя. Issues с метками используются как синхронизированный backlog, а эта Markdown-доска — локальный Kanban-снимок.
