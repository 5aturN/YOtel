# Ревью кода и статический анализ

## Объект ручного ревью

Проверен модуль `src/yaotel/pricing.py` (функция расчёта цены и вспомогательные константы).

| Критерий | Результат | Решение |
|---|---|---|
| Читаемость и имена | `PriceCalculator`, `base_price_kopecks`, `check_in`, `check_out` отражают назначение | Оставлено без изменений |
| Валидация | Нулевая цена и неупорядоченные даты отклоняются | Проверяется unit-тестами |
| Денежная арифметика | Используются целые копейки и `Decimal`, не `float` | Оставлено без изменений |
| Дублирование | Повторяющихся блоков нет | Дополнительный слой абстракции не вводился |
| Магические значения | Коэффициент выходного тарифа и дни недели вынесены в константы класса | Оставлено без изменений |
| Границы дат | Выезд не тарифицируется; пятничная и субботняя ночи получают коэффициент 1,15 | Добавлены отдельные тесты |

## Статический анализ

- Ruff: первоначально обнаружил только несортированный импорт (`I001`) в `pricing.py`; порядок импортов исправлен через `ruff check --fix`. Повторный запуск — без замечаний.
- Bandit: `bandit -r src/yaotel -ll` завершился без находок уровней Medium/High.
- Ошибки и замечания исправляются до коммита; те же команды включены в workflow `Build and Test`.
