# ЯОтель

## Назначение
«ЯОтель» — учебный проект системы бронирования и управления гостиницей. Проектируемая система помогает гостям искать номера и оформлять бронирования, а сотрудникам — управлять номерным фондом и обслуживанием гостей.

## Основные функции
- поиск свободного номера по датам, категории и числу гостей;
- создание и сопровождение бронирования;
- учет статусов номеров, включая уборку и ремонт;
- оформление заселения и выселения;
- уведомления гостям и отчетность для управляющего.

Статус проекта: учебная концепция.
