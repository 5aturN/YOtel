# ЯОтель

Учебный проект модульного монолита для поиска гостиничных номеров, бронирования и работы сотрудников рецепции. Реализация развивается по практическим заданиям №15–30.

## Текущий этап

На этапах №16–21 настроены CI, тесты и статический анализ; требования проверены и сведены в матрицу. Реализованы поиск доступных номеров и создание бронирований с проверкой пересечений и расчётом тарифа. Код разделён на API, сервисный, репозиторный и модельный слои; 10 тестов проходят.

## Запуск локально

Требуются Python 3.11+ и pip. Для Windows PowerShell: создать и активировать виртуальное окружение, затем установить dev-зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m uvicorn yaotel.main:app --app-dir src --reload
```

Проверка состояния: открыть `http://127.0.0.1:8000/health`. Интерактивная схема API будет доступна по адресу `/docs` по мере добавления endpoint-ов.

## Сборка контейнера

```powershell
docker build -t yaotel:dev .
docker run --rm -p 8000:8000 yaotel:dev
```

## Проверка

```powershell
python -m unittest discover -s tests -v
python -m pytest -q
```

## Секреты

Скопируйте `.env.example` в `.env` и задайте собственные значения для локальной среды. Реальные ключи и пароли не добавляйте в Git; production-переменные следует задавать в секрет-хранилище окружения.
